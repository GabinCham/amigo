# Amigo

App web pour parler espagnol 30 jours avec Amigo : quotidien, souvenirs de voyage, foot.

Site : https://gabincham.github.io/amigo/

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000) dans Chrome ou Safari (micro + voix).

Dans **Toi**, tu peux coller une clé OpenAI pour une conversation plus libre. Sans clé, Amigo reste sur des phrases préparées. La clé reste dans le navigateur.
